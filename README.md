# Tarrelo — site tarrelo.com

Site statique (HTML/CSS/JS sans build), hébergé sur Netlify. Chaque push sur `main` redéploie le site.

- `index.html` : page d'accueil (sélecteur de métier et calculateur en JS natif en bas de page)
- `mentions-legales.html`, `cgv.html`, `confidentialite.html`, `404.html`
- `assets/` : logos, vignettes, image de partage, photo, polices auto-hébergées (Inter, Plus Jakarta Sans)
- `netlify.toml` : redirection www → apex, en-têtes de sécurité, cache
